## Responsive mobile update
This version preserves the approved desktop homepage exactly at desktop widths.

At 700px and below, the homepage automatically switches to a true mobile layout with:
- mobile navigation / hamburger menu
- full-screen phone hero
- readable live HTML typography
- stacked benefits
- full-width Homes / Businesses / Facilities cards
- stacked service cards
- mobile Why SOVRN section
- full-width van image
- mobile Detect / Verify / Control section
- touch-friendly single-column consultation form

The secondary pages retain their existing responsive layouts.

No separate mobile URL is needed. The browser automatically selects the appropriate layout based on screen width.
