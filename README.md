# SOVRN Technologies — Final Exact Design

This project was created fresh from the final approved SOVRN homepage artwork only.

It intentionally does NOT reuse layout, CSS, sections, images, or components from the prior website versions.

Included:
- The exact final approved visual design
- Header navigation hotspots
- Working consultation buttons
- Working service links
- A real HTML form overlaid precisely on the approved form artwork
- Mailto fallback for form submission

Important:
The page is designed to match the approved desktop artwork exactly. Because the approved artwork is a single 1024×1536 composition, the mobile version scales the artwork proportionally rather than rearranging the design.

Before launch, replace `info@sovrnisi.com` in `script.js` if you want a different destination email.
