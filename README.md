# SOVRN Technologies — Multi-Page Website

This package keeps the approved homepage and adds dedicated secondary pages in the same visual language.

Pages:
- index.html — approved homepage
- residential.html
- commercial.html
- services.html
- about.html
- contact.html

Shared secondary-page styling:
- secondary.css
- secondary.js

The homepage navigation now opens the dedicated pages.

Upload every file and the entire `assets` folder to the root of your existing `sovrn-technologies` GitHub repository. Commit the changes; Vercel should redeploy automatically.

The contact form currently uses `mailto:info@sovrnisi.com`. Replace that address in `secondary.js` and `script.js` if needed.
